One More Boop

Et meningsløs spill som tester din trykking på en knapp uten begrensninger, med enkel grafikk, belønninger og intuitiv kontroll - eksekvert via en nettleser på en hvilken som helst enhet.

Hovedidé

One More Boop er et enkelt spill hvor spilleren trykker på en knapp så mange ganger som mulig uten en bestemt tid. Spillet er designet for å være underholdende og utfordrende, samtidig som det ikke gir noen reell verdi. Mer informasjon finner du her: GitHub

Hva prosjektet inneholder

  • Spillmekanikk for knappetrykk
  • Scorebord og statistikk
  • Intuitiv kontroll og tilbakemelding
  • Responsivt og tydelig grensesnitt

Tech Stack

Applikasjonslag: React 19, TypeScript 5.9, Vinext

UI og styling: Tailwind CSS, CSS, Shadcn React, Lucide React

Effekter: CSS Keyframe, Web Audio API, Vibration API

Build og hosting: Node.js 22.13+, npm, Vite 8, OpenAI Sites, Wrangler

Hva jeg lærte

I dette prosjektet lærte jeg mye om React og TypeScript, samt hvordan man bygger en responsiv og brukervennlig frontend med Tailwind CSS og Shadcn React. Et simpelt trykk på en knapp kan skape en imponerende brukeropplevelse, hvor progresjonen blir synlig gjennom tilbakemeldingen og scorebordet.
